范围：五个家族的视觉语法、家族差异矩阵、每家族 12 个 Catalog 角色位，以及待用户裁决的问题。

## 1. F2 共用边界

### 1.1 已锁定的 Contract v1.1 事实

- 单页固定为 `3:4`；标准物理 spread 的 `3:2` 是由两张单页派生的只读事实，不重复持久化。
- `page` 是默认 scope，且只能改变当前页。`spread` 只能由真实 `cross-gutter-photo` 或照片 Slot—Note Slot 的合法 `cross-page-pair` 客观证明；双图并置、共享网格、共享色彩、视觉平衡、标题跨页或 Color Field 跨线都不能自证 spread。
- 所有照片框都使用 `cover`。家族语法只能规定合适比例、焦点风险和裁切倾向，不能以未填满的照片框制造“留白”。
- Photo Note 永远通过照片/placement 身份绑定。几何邻近不能替代 `adjacent | aligned | edge-related | indexed | cross-page-pair | overlay` 关系；本阶段不新增关系种类。
- Note 是纯文字；不使用卡片、胶囊、阴影或装饰容器。不支持 Note 的版面隐藏 Note 但不删除原始内容。
- 色彩只使用受控 `paper | ink | muted-ink | photo-mat | accent-1 | accent-2 | accent-3 | inverse-ink` token。功能色域可以组织页面，但色域本身不构成 spread evidence。
- 文字只使用 `title | deck | label | folio | caption | note | index` 七种 role，以及受控 typography token 和对齐语义；不开放字体 URL、任意字号或 CSS。
- Catalog 词表以现有受控枚举为准：topology、composition axis、reading direction、color strategy、pace 与 risk 都由 Catalog 声明；scope、照片能力、面积/密度、Note 关系与 bleed 从 Definition 派生。
- Editor 与 Reader 共用 Renderer/Plan。单页聚焦视角、左右页、真实比例和连续 spread 上下文仍需未来人工视觉 Gate。
- 所有 Slot 和 Color Field 都是固定几何。Optional Note 缺失时，系统只是不产生对应 Note assignment；不会移动或放大照片、移动其他文字、回收 Note 几何，也不会合并、删除或改变 Color Field。因而 optional Note 缺失后的固定留白与固定色域必须仍是完整构图；只为 Note 服务的几何或色域必须搭配 required Note，或拆成另一项 Recipe。

### 1.2 本文件的量词

为避免把 F2 偷渡成 F3，以下词语只有家族级含义：

| 量词 | 定义 |
| --- | --- |
| 画布面积 | 单页按一张 `3:4` 页计算；spread 按完整 `3:2` 双页计算 |
| 照片覆盖率 | 所有照片框面积之和占画布面积；重叠不重复计算。本阶段只给目标带宽 |
| 主图面积 | 最大照片框占画布面积的带宽，不是具体矩形 |
| 次图面积 | 单张辅助照片的典型面积带宽 |
| 页边距 | 内容安全边界相对单页短边的比例；内外边距可不同，但不在 F2 给坐标 |
| 短 Note | 建议 1–2 行、约 12–60 字符；最终上限由 F3 的实际 typography token 和 Compatibility 复核 |
| 中 Note | 建议 2–4 行、约 40–140 字符；不允许渲染时静默截断 |
| 低/中/高密度 | 照片覆盖率分别约为 `<35%`、`35–65%`、`>65%`；Catalog 的派生阈值仍以 Contract 实现为权威 |

面积带宽允许未来 Anchor 在内部选择一个值，但不允许突破家族规则。若实际可读性、主体安全或 Contract Validator 要求更严格，以更严格者为准。

### 1.3 五家族共同的禁区

1. 不以换色、镜像、微调间距或更换文字 role 单独构成新 Recipe。
2. 不用随机旋转、自由重叠、贴纸、纹理、滤镜、渐变或每 Recipe 专用 Renderer 制造差异。
3. 不让标题、Note、页码或色块覆盖照片；现代 Contract 要求文字具有唯一、可确定的承载面。
4. 不把照片主体默认推入裁切边缘或书脊损失区；`cover` 必须与 placement focus 一起验收。
5. 不靠无意义空槽处理照片不足；照片过多进入 `unplacedPhotoIds`，照片不足必须有可解释的兼容状态。
6. 不把两个各自独立的 page 布局包装成 spread。真正 spread 必须由 `cross-gutter-photo` 或照片—Note `cross-page-pair` 证明；双图对话本身仍是 page 语义。
7. 不把 optional Note 当作动态版式开关；其缺失不能触发 reflow、几何回收或 Color Field 变化。

## 2. Editorial Family Bible

研究依据：Research Dossier 的 A01/A03/A04/A05/A07、P01/P04/P06、E01/E04、G01；重点采用 R-01（系统先于变化）、R-02（图像网格与文字基线分工）、R-05（Note 关系显式化）与 R-08（文字职责层级）。

### 2.1 目标与情绪

Editorial 把照片当作一篇被编辑过的报道：图像、标题、deck、folio、label 与 Photo Note 各有明确职责，读者先获得叙事入口，再在主图、辅助图和文字证据之间移动。情绪可以庄重、亲近或调查式，但必须保持清楚的编辑判断，不能变成均匀图片目录。

### 2.2 内容适配

**适合：** 有事件线索、人物与环境关系、主次明确的纪实组照；需要标题或短说明建立上下文的旅行、庆典、家庭叙事；一张关键图加一至三张证据图；具有可配对 Note 的人物、地点、时刻或物件。

**不适合：** 没有任何主次关系的大批同质照片；只能依靠逐图编号理解的档案集合；需要长篇正文才能成立的文章；主体贴边且无法安全裁切的整组图片；只想获得纯粹单图凝视而不需要编辑文字的内容。

### 2.3 网格、主轴、边距与书脊

- 基础骨架：单页以 6 列为默认分析网格，可合并成主图宽区、窄文字栏或辅助图区；文字基线与图像列是相关但独立的节奏。
- 允许的主轴：以 `vertical`、`horizontal` 或 `edge` 为主；同一版面只能有一个第一主轴，辅助图不能形成第二个同等入口。
- 页边距：外侧和上下安全边距通常为短边的 6–11%；文字栏不得小于家族安全边距。内侧边距通常比外侧多 2–4 个百分点，除非存在合法跨页关系。
- 书脊策略：page 版面把书脊当作硬边界；spread 只允许真实跨书脊主图或照片与绑定 Note 分处左右页的 `cross-page-pair`。标题跨页、双图对话或左右编辑平衡都不能证明 spread。
- 网格偏离：允许一张主图越过一个列组或抵达单侧出血边，但偏离必须强化叙事主次；不能用无规则错位制造“杂志感”。

### 2.4 图像尺度、数量与比例

- 主图典型面积：单页 38–72%；spread 35–68%。低于此范围时，必须由标题主导或明确的图文关系补足入口。
- 次图典型面积：单张 8–24%；次图总权重不得与主图争夺第一入口。
- 照片数：通常 1–4；5 张只用于明确的证据序列，不作为家族常态。
- 优先比例：portrait、landscape；square 可作证据图或人物肖像。ultra-wide 只适合横向 band 或经过验证的跨书脊主图，默认高风险。
- 主次下限：有多图时，最大图面积通常应至少为任一次图的 1.7 倍；若接近等大，必须把结构明确转成 diptych 对话，而不是伪主次。

### 2.5 出血、留白与密度

- 目标密度：中密度为主，照片覆盖率约 42–68%；可有少量低密度标题开篇和高密度证据页。
- 出血：允许局部或全页单侧出血，作为报道节奏中的强调；该角色自身必须在单页中建立清楚层级。后续 sequencing 可用框内或留白页面形成节奏反差，但不能把特定相邻页面当作成立前提。
- 留白职责：分隔标题、主图、证据图与 Note；空白必须标明信息层级，不得只是因为内容不足。
- 文字安全：标题与 Note 始终落在 `paper` 或唯一可解析的受控色域上，不叠压照片。

### 2.6 阅读方向与进入点

- 默认入口是标题或主图，两者只能有一个压倒性第一层级；deck 负责把读者送入图像而不是建立第二标题。
- 常用路径为 `top-down`、`ltr/rtl`（按页侧镜像）或 `inward/outward`；不使用 radial 阅读。
- 多图必须形成“主图 → 证据图 → Note/folio”或“标题 → 图像对话 → Note”的路径；禁止读者先撞上页码或装饰 label。
- spread 应能从左右任一侧识别关系，但真正的意义必须在完整展开时成立。

### 2.7 Note 能力

- 家族覆盖 `none | optional | required`，但 Catalog 角色位以 optional 为主。
- 允许 `adjacent`、`aligned`、`edge-related`、`indexed` 和真正 spread 中的 `cross-page-pair`；不采用 `overlay` 作为家族常规语法。
- caption：短 Note，1–2 行，约 12–60 字符，用于人物、地点、时间或事实。
- note：中 Note，2–4 行，约 40–140 字符，用于补足照片不可见的上下文。
- index：只在多图证据组中使用；每个标记必须可唯一回指照片，不能仅靠相对距离。
- Optional Note 缺失时，Note Slot 为空，但照片、其他文字和 Color Field 的几何完全不变；该固定空白必须预先作为节奏、分隔或安全空间独立成立，不能依赖运行时“收回”。若空白只因 Note 存在才合理，则该 Note 必须 required，或将有/无 Note 拆成两个独立 Recipe。

### 2.8 文字层级

推荐层级为 `title > deck > note/caption > label > folio`；`index` 在使用时与 caption 同级但具不同职责。

- `title`：只出现一次，承担叙事入口；不以全大写作为唯一识别。
- `deck`：可选，只说明上下文，不重复标题。
- `label`：栏目、日期或章节信号；不得冒充 Photo Note。
- `folio`：最弱导航层，使用 inward/outward 逻辑避开书脊。
- `caption/note/index`：永远保留照片绑定；文字宽度和行数由未来 Anchor 验证。

### 2.9 颜色

- 默认 `paper`；允许 `single-accent` 标识入口、章节或 label。
- 可少量使用 `zoned`，但色域必须服务标题区/证据区的分工，不能让 Editorial 变成 Chromatic。
- 普通文字静态对比不低于 4.5:1；`muted-ink` 只用于 label/folio 等次要信息，仍须通过实际尺寸视觉 Gate。
- 禁止：三个以上等权强调色；标题区和 Note 区使用不同颜色却没有信息职责；以颜色代替照片绑定；大面积节奏色块主导全页。

### 2.10 scope 配比

建议 12 个角色位中 **10 个 page / 2 个 spread**。两个 spread 角色位分别承担真实跨书脊主图和照片—Note 跨页配对；其余图像对话全部是 page。任何 spread 若缺少对应 evidence 都必须淘汰或改写，不为维持配额伪造 scope。

### 2.11 Do / Don't

**Do**

1. 让标题、主图、证据图和 Note 各自有单一职责。
2. 用主次面积差而不是装饰效果建立叙事顺序。
3. 用窄文字栏和基线节奏控制 Note，而不是挤压照片。
4. 让 page 在单页聚焦视角中独立闭合。
5. 让 spread 的不可拆分事实来自照片或 Photo Note 关系。
6. 让 optional Note 缺失后的固定空白仍是完整构图，不假设其他 Slot 会移动或扩张。

**Don't**

1. 不把等大、等距多图称为 Editorial；那属于 Grid/Contact。
2. 不让 deck、label 或 folio抢过主图。
3. 不把标题跨页当作 spread evidence。
4. 不让每张图都配相同长度文字，造成目录式重复。
5. 不以大色块和多色节奏替代编辑层级。
6. 不靠照片重叠或文字压图制造杂志感。

### 2.12 与其他家族的边界

- 对 Grid/Contact：Editorial 必须存在不对称主次与叙事入口；若所有照片等权并以比较/索引为目的，归 Grid/Contact。
- 对 Quiet：Editorial 至少有一项显式编辑线索（标题、deck、Note、证据图或序列）；若文字极少、停留完全由单图和留白构成，归 Quiet。
- 对 Dynamic：Editorial 的方向服务层级而非速度；若尺度跳变、边缘切分和斜向趋势成为第一识别，归 Dynamic。
- 对 Chromatic：Editorial 的色彩是辅助层；若色域承担分组、节奏或入口的主要结构，归 Chromatic。

## 3. Grid / Contact Family Bible

研究依据：Research Dossier 的 A01/A02/A05/A06、P02/P05、L01/L04、E02/E03、G03、D01/D02；重点采用 R-01（稳定模数）、R-03（尺度控制扫描速度）、R-05（索引不靠邻近）与 R-11（超量内容可解释）。

### 3.1 目标与情绪

Grid/Contact 把照片视为可比较、可扫描、可索引的档案单元。秩序、重复和组间差异是第一语言；读者应能快速发现相似、变化、缺席和序列。它可以严谨或粗粝，但不能是随意拼贴，也不能偷偷依赖一张巨大的主图来成立。

### 3.2 内容适配

**适合：** 同一事件的连续动作、人物系列、物件分类、地点勘察、过程记录、表情或细节变化；照片间比例相近且值得横向比较；需要编号/索引的档案内容。

**不适合：** 只有一张真正重要的英雄图；每张照片都需要长篇解释；比例和视觉权重极端混杂而无法分组；主体大量贴边且小格裁切会持续伤害内容；必须通过不对称冲撞表达速度的素材。

### 3.3 网格、主轴、边距与书脊

- 基础骨架：单页 4、6 或 8 列模块网格；一个角色位只采用一种基本模数，不能在同页混用无公倍数的列系统。
- 主轴：`horizontal` 或 `vertical`，少量 `around` 用于有明确中心索引的结构；不采用 `diagonal`。
- 页边距：短边的 4–8%，用于保持模块总宽稳定；外边距和栏沟应从同一间距单位派生。
- 栏沟：在一个角色位内保持恒定；组间间距可为栏沟的 2–3 倍，以明确分组。
- 书脊策略：page 是常态。两页共享同一网格不构成 spread；本家族仅保留两类 spread：至少一张照片真实跨书脊的 Contact Band，以及照片与 required `index` role Note 分处左右页、relation 为照片—Note `cross-page-pair` 的索引对答。

### 3.4 图像尺度、数量与比例

- 主图典型面积：等权网格不设主图，每格通常 5–22%；分级网格的主图 25–45%，且仍需保留至少两个可比较单元。
- 次图典型面积：5–18%；同组内面积差不超过约 20%，除非明确标记为“样本—细节”层级。
- 照片数：通常 3–9；2 张只用于严格比较；10–12 张只用于高密度 contact/index 角色且必须保证小屏可辨。
- 优先比例：square、portrait；landscape 适合横 band 或统一横向系列。ultra-wide 默认风险高，只有整组都适配横 band 时才接受。
- 混合比例：必须按行、列或组分隔；不得把不同比例随意切成 mosaic 后称为 contact sheet。

### 3.5 出血、留白与密度

- 目标密度：中高至高，照片覆盖率约 55–84%。低密度只用于稀疏比较，不得失去重复性。
- 出血：通常无出血；允许一条横向或纵向 band 触边，但不能破坏模块可计数性。
- 留白职责：栏沟表示同组关系，较大间距表示组间关系，外边距表示档案边界。三者不能任意互换。
- 空槽：不把空槽伪装成“缺席样本”。照片不足时应判定 needs-content 或使用明确支持较少照片的角色位。

### 3.6 阅读方向与进入点

- 默认 `ltr/rtl` 或 `top-down`；方向由编号、模块顺序和组间间距共同确认。
- 第一入口是序列的第一个单元或 index label，不是一张任意放大的照片。
- 高密度角色必须有明确行列顺序；禁止 radial 扫描和多条相互竞争的 Z 形路径。
- 分级网格先读主样本，再读同行/同列比较项；主图不能占据超过半页，否则会滑向 Editorial。

### 3.7 Note 能力

- 以 `none` 与 `optional` 为主；required 只用于“索引即结构”的角色位。
- 首选 `indexed`，其次 `aligned` 和 `adjacent`；`edge-related` 只用于 band 端点；不使用 `overlay`。
- indexed Note 通常为 1 行、约 6–36 字符；可用短编号、地点、时间或样本标签。
- 中 Note 只允许作为整组说明，不为每张图重复长段文字；逐图中 Note 会破坏比较速度。
- 无 Note 时仍由行列顺序成立；有 Note 时编号必须唯一、稳定并能回指照片身份。
- Optional Note 缺失时不发生 reflow；既有行列、栏沟与固定空白必须仍构成完整 Contact 结构。只有 required `index` role Note 才能承担不可缺失的索引或 spread evidence 职责。

### 3.8 文字层级

推荐 `index > label > caption > folio`；`title` 只作为组题，`deck` 极少使用，`note` 不作为常规逐图层。

- `index` 是家族标志性 role，但不能用作装饰数字。
- `label` 标识批次、日期、位置或组别。
- `caption` 只补充无法从比较中看出的最小事实。
- `folio` 不得进入照片模块内部。

### 3.9 颜色

- 默认 `paper` 或 `single-accent`；强调色可标记选择、组别或索引入口。
- 允许受限 `zoned`，但每个色域必须与一个图像组或索引组一一对应；若颜色节奏本身成为主要观看对象，归 Chromatic。
- 文字与承载面保持至少 4.5:1；小 index 还需人工检查实际单页可读性。
- 禁止：每格随机颜色；同组用不同强调色却无分类含义；用颜色补救不清楚的行列顺序。

### 3.10 scope 配比

建议 **10 个 page / 2 个 spread**。两者必须结构不同：一个由真实 `cross-gutter-photo` 形成跨书脊 Contact Band；另一个由照片与 required `index` role Note 的 `cross-page-pair` 形成跨页索引对答。共享网格、连续编号或双页比较均不能替代这两类 evidence。

### 3.11 Do / Don't

**Do**

1. 用单一模数和恒定栏沟建立可见秩序。
2. 让每个格子在序列中有可解释位置。
3. 用组间距而不是随意放大区分子集。
4. 让 index 唯一回指照片身份。
5. 为混合比例建立明确行、列或组。
6. 在小屏检查最小照片仍能承担比较信息。

**Don't**

1. 不把任意 mosaic 称为网格。
2. 不以一张超过半页的英雄图支配 contact 结构。
3. 不让每张图附带中长 Note，拖慢扫描。
4. 不把共享双页网格当作 spread evidence。
5. 不用随机缺口模拟接触印样。
6. 不只改变列数、颜色或镜像来凑满 12 个角色位。

### 3.12 与其他家族的边界

- 对 Editorial：Grid/Contact 的主要价值是等权比较和索引；出现明确英雄图与报道层级时归 Editorial。
- 对 Quiet：Grid/Contact 即使留白很大，也必须存在两个以上重复/比较单元；只有单图或纯配对停顿时归 Quiet。
- 对 Dynamic：网格偏离不能破坏行列可预测性；方向冲撞和尺度跳变成为第一语言时归 Dynamic。
- 对 Chromatic：颜色只辅助分类；若色域比网格更先被识别，归 Chromatic。

## 4. Quiet Family Bible

研究依据：Research Dossier 的 A03/A07、P02/P03/P05、M01、L02/L03、E01/E04、G02、D01；重点采用 R-03（尺度即观看速度）、R-06（留白改变停留）、R-10（书脊是结构边界）与 R-12（真实比例/连续上下文 Gate）。

### 4.1 目标与情绪

Quiet 用尺度、停顿和留白延长观看时间。它不追求“空”，而是让每张照片得到明确的呼吸、重心和沉默关系；文字只在不可替代时出现。结构应温和但精确，不能把十二个角色都简化成“小图居中”。

### 4.2 内容适配

**适合：** 肖像、静物、风景、室内、抽象细节、情绪性瞬间；一至两张本身足以承担停留的照片；需要让纸面边界、图像尺度或相邻空白参与意义的内容。

**不适合：** 需要快速比较的大批照片；必须依靠标题和说明建立语境的报道；动作连续、强方向切分的素材；低分辨率且无法承受孤立凝视的图片；主体贴边又没有可用 focus 的照片。

### 4.3 网格、主轴、边距与书脊

- 基础骨架：4 列或 6 列隐形网格，用于控制图框和文字的静默对齐；网格本身不显露为重复模块。
- 主轴：`center`、`edge` 或稳定的 `vertical/horizontal`；每个角色位只允许一个静态重心。
- 页边距：短边的 10–22%；可有一侧更宽的方向性空白，但宽窄差必须形成观看方向而非偶然偏心。
- 书脊策略：内侧通常比外侧更保守，主体不靠脊。spread 只用于真实 `cross-gutter-photo` 停顿，或照片与绑定 Note 分处左右页的远距离 `cross-page-pair`；双图对话本身不能成为 spread。
- 变化来源：框内/出血、中心/边缘、单图/配对、尺度大/中/小、文字有/无五个轴交叉变化；不靠反复缩小居中凑数。

### 4.4 图像尺度、数量与比例

- 主图典型面积：18–58%；全出血例外为 75–100%，但必须成为整套语法中的强停顿而非常态。
- 次图典型面积：10–28%；双图时可等权，也可用约 1.4–2.0 的温和主次比。
- 照片数：通常 1–2，少量 3 张角色用于缓慢序列；不超过 3。
- 优先比例：portrait、landscape、square 均可；比例应尽可能尊重原图气质。ultra-wide 只适合横向低带宽框或经验证的 spread，且主体边缘风险高。
- 小图下限：不能小到只成为装饰符号；单页聚焦视角必须仍能辨认照片的核心信息。

### 4.5 出血、留白与密度

- 目标密度：低至中，照片覆盖率约 18–48%；全出血停顿角色除外。
- 出血：以框内为常态；全出血只用于一张足够强、主体安全的照片，并且该角色自身必须成立。它可以在后续 sequencing 中与低密度页面形成反差，但不依赖特定前后页才能有效。
- 留白职责：形成停顿、方向、尺度对照或对页期待。无内容导致的空白不算 Quiet。
- 空间分配：至少一块连续负空间应明显大于普通页边距，使重心可感知；但不能形成等待填充的标准矩形空槽。

### 4.6 阅读方向与进入点

- 第一入口始终是照片；标题不得先于照片抢夺注意。
- 常用 `center` 对应静态凝视，`inward/outward` 对应书页方向，`top-down` 对应缓慢序列。
- 单图页面的路径是“进入 → 停留 → 离开”，而非多站点扫描。
- 双图要么形成并置对话，要么形成时间停顿；不得同时叠加标题、多个 Note 和强调色制造第三入口。

### 4.7 Note 能力

- 以 `none` 为主，少量 `optional`；required 仅保留给跨页 Photo Note 关系角色。
- 允许 `adjacent`、`aligned`、`edge-related` 和 spread 中的 `cross-page-pair`；不使用 `indexed` 作为常态，不使用 `overlay`。
- Note 通常 1–3 行、约 12–90 字符；优先 caption，其次 note。超过范围应换用 Editorial，不压缩字号。
- Note 与照片之间可以有较远留白，但绑定必须由关系数据明确；远距离不等于关系模糊。
- 无 Note 时，页面视觉必须仍完整，且不出现预留文字带。

### 4.8 文字层级

推荐 `caption/note > folio > label`；`title` 和 `deck` 仅出现在极少转场角色，`index` 不属于本家族常规语言。

- caption/note 保持弱于照片，但不能小到不可读。
- folio 可被隐藏或置于最弱层；不能成为边缘装饰。
- label 只标识必要章节/日期；若需要显著标题，通常转入 Editorial。

### 4.9 颜色

- 以 `paper` 为绝对主流；允许极低频 `single-accent` 作为章节停顿。
- 可使用单一 `photo-mat` 与纸色建立安静层次，但不能模拟未填满照片框；照片本身仍 `cover`。
- 不使用 `rhythmic`；`zoned` 只允许一块安静承载面，且不能先于照片被识别。
- 禁止：高饱和多色、相邻互补色、反色小字、颜色分组、色块切分照片观看路径。

### 4.10 scope 配比

建议 **10 个 page / 2 个 spread**。spread 分别用于跨书脊单图停顿和照片—Note 远距离 `cross-page-pair`；双图对话和双页留白都不能证明 spread。

### 4.11 Do / Don't

**Do**

1. 用不同的尺度、重心和边缘关系制造十二种停顿。
2. 把连续负空间当作有方向的构图元素。
3. 优先尊重照片比例与主体安全。
4. 让文字保持短、少、明确绑定。
5. 用框内与全出血的稀缺反差控制节奏。
6. 在单页聚焦视角确认小图仍可观看。

**Don't**

1. 不把所有角色位都做成小图居中。
2. 不用空白掩盖照片不足或未完成布局。
3. 不把长文字压成更小字号。
4. 不让标题、色块或 folio 成为第一入口。
5. 不把对页平衡当作 spread evidence。
6. 不用大批等权小图；那属于 Grid/Contact。

### 4.12 与其他家族的边界

- 对 Editorial：Quiet 的第一入口永远是照片和停顿；标题/证据层级成为必要条件时归 Editorial。
- 对 Grid/Contact：Quiet 最多三张且不以扫描比较为目的；重复模块和 index 成为骨架时归 Grid/Contact。
- 对 Dynamic：Quiet 的不对称用于稳定重心，不用于速度和冲撞；尺度跳变或斜向切分成为第一语言时归 Dynamic。
- 对 Chromatic：Quiet 的颜色退居纸面气氛；色域承担分组或节奏时归 Chromatic。

### 4.13 12 个 Catalog 角色位草案

| 角色位 | 结构职责 | 内容负载 | Note / 文字职责 | 与同家族其他角色位的主差异 |
| --- | --- | --- | --- | --- |
| 01 | 中尺度中心凝视 | 1 张 | 无 Note；弱 folio | 中心重心基线角色 |
| 02 | 小尺度远距凝视 | 1 张 | optional 短 caption | 最大负空间与最慢进入 |
| 03 | 大尺度框内停顿 | 1 张 | 无 Note | 最大框内图，仍保留纸边 |
| 04 | 单图全出血停顿 | 1 张 | 无 Note | 唯一高密度断点 |
| 05 | 内侧避让单图 | 1 张 | edge-related caption 可选 | outward 重心与书脊安全 |
| 06 | 外侧牵引单图 | 1 张 | aligned caption 可选 | inward 视觉回流，不是 05 镜像复制 |
| 07 | 水平双图对话 | 2 张等权 | 无 Note | 横向停顿与并置 |

| 12 | 远距离照片—Note 对答 | 1 张；spread | required `cross-page-pair` 中短 Note | 空白承载跨页语义而非装饰 |

## 5. Dynamic Family Bible

研究依据：Research Dossier 的 A02/A04/A06/A08、P01/P03/P04、M01/M02、L01/L04、E02/E03、G02、D02、DM01；重点采用 R-03（尺度跳变）、R-04（cover 不等于主体安全）、R-07（受控出血）与 R-10（书脊结构事实）。

### 5.1 目标与情绪

Dynamic 通过方向、尺度跳变、不对称和受控切分制造运动感。读者应立即感到“从哪里进入、往哪里去”，但在触控单页视角仍能清楚读完；运动来自可预测的结构张力，不来自随机旋转、贴纸或重叠。

### 5.2 内容适配

**适合：** 舞蹈、运动、游行、表演、交通、街头动作、快速情绪变化；具有清楚方向、动作前后或远近切换的图组；可以承受裁切和边缘张力的照片。

**不适合：** 需要长时间静观的细腻单图；主体四周都需要完整保留的照片；高度相似而应比较分类的档案；依靠长文字解释的内容；焦点不可迁移且主体贴近预期裁切边的图片。

### 5.3 网格、主轴、边距与书脊

- 基础骨架：6 列或 8 列网格，配合 3–6 条水平分带；变化发生在合并、切分和尺度跳变，基础对齐仍可追踪。
- 主轴：`diagonal`、`horizontal`、`vertical` 或 `edge`；“diagonal”是由矩形边界和尺度趋势形成的视觉方向，不是旋转 Slot。
- 页边距：短边的 3–9%；至少一条边可作为主动出血/切入边，其余安全边保持可预测。
- 书脊策略：page 仍是主力。spread 只用于动作照片真实跨书脊，或照片与绑定 Note 分处左右页的 `cross-page-pair`。左右双图的向心、离心、汇聚或动作连续都不能自证 spread；关键人物面部、文字和动作关节不得落入中心风险区。
- 张力规则：同页最多两个强方向，其中一个必须明显主导；三个以上等强方向视为噪声。

### 5.4 图像尺度、数量与比例

- 主图典型面积：45–88%；次图典型面积 8–28%。
- 照片数：通常 1–4；5 张只用于连续动作 band，不用作任意 mosaic。
- 尺度跳变：多图时最大图通常为最小图的 2.2–5 倍；超过此范围小图可能沦为装饰，需人工验证。
- 优先比例：landscape、square；portrait 适合竖向切分或边缘推进。ultra-wide 适合横向 band/跨脊动作，但书脊和主体风险高。
- 裁切：允许强 `cover` 裁切，但必须为每张高风险照片保留可迁移 focus；不能让默认中心焦点必然失败。

### 5.5 出血、留白与密度

- 目标密度：中高至高，照片覆盖率约 58–90%；低密度只用于单条强方向，不得滑向 Quiet。
- 出血：局部/全出血是核心节奏；一个角色位最多由两条边承担主动出血，避免四边同时失去方向。
- 留白职责：形成“跑道”、切口或方向缓冲；不是均匀四周留白。
- 文字必须停在稳定承载面，不能被照片或色块切过；Dynamic 的速度不授权降低可读性。

### 5.6 阅读方向与进入点

- 默认入口是最大图的高对比边、动作方向或切分起点。
- 可用 `ltr/rtl`、`top-down/bottom-up`、`inward/outward`；`radial` 只在矩形环绕结构中谨慎使用，不依赖旋转。
- 路径必须能用一句动词描述：推进、坠落、上升、横扫、折返或汇聚。无法描述则结构可能只是随机不对称。
- 单页聚焦时仍要看到入口与终点；不能把关键路径完全寄托在对页。

### 5.7 Note 能力

- 以 `none` 与短 `optional` 为主；required 仅用于跨页动作—说明关系。
- 允许 `edge-related`、`aligned`、`adjacent` 和 `cross-page-pair`；`indexed` 仅用于连续动作编号；不使用文字 `overlay`。
- Note 通常 1–2 行、约 12–70 字符；必须停在方向路径之外的稳定区。
- 中 Note 若超过约 100 字符，优先转 Editorial；不通过缩窄文字或更小字号塞入。
- 无 Note 时，方向结构必须闭合；Note 不得成为平衡画面的配重块。

### 5.8 文字层级

推荐 `title/label > caption/note > folio`，但文字总量必须少。

- `title` 可作为方向起点或终点，仍须在独立承载面。
- `label` 可标记动作阶段或时间。
- `index` 只用于连续动作，不用于普通装饰编号。
- `folio` 应退到不与主动边竞争的位置。
- `deck` 极少使用；长 deck 会削弱速度。

### 5.9 颜色

- 允许 `paper`、`single-accent` 和受限 `zoned`。强调色可标出方向起点、终点或稳定文字区。
- `rhythmic` 可用，但色彩节奏必须从属于图像尺度/方向；若颜色成为第一结构，归 Chromatic。
- 普通文字至少 4.5:1；反色只用在完全落入单一高对比色域的文字。
- 禁止：用多色弥补不清楚的方向；对角渐变；透明叠色；把每张图涂成不同色组。

### 5.10 scope 配比

建议 **10 个 page / 2 个 spread**。spread 只覆盖跨书脊横扫与照片—Note 跨页对答；双图汇聚、向心或离心方向均在单页内完成。

### 5.11 Do / Don't

**Do**

1. 用矩形尺度和边界建立方向，不旋转 Slot。
2. 给每个角色位一个可说出的动作路径。
3. 用一条主方向和最多一条辅方向控制张力。
4. 让 placement focus 承担强裁切的主体保护。
5. 把文字放在稳定、唯一的承载面。
6. 同时验证完整 spread 与单页聚焦视角。

**Don't**

1. 不用随机旋转、贴纸、阴影或任意重叠。
2. 不让四条边同时出血而失去方向。
3. 不让对页补救本页没有入口的问题。
4. 不把任意尺寸拼贴称为 dynamic mosaic。
5. 不以色彩节奏代替结构速度。
6. 不把关键主体或文字放进书脊损失区。

### 5.12 与其他家族的边界

- 对 Editorial：Dynamic 的第一语言是动作路径和尺度冲撞；图文层级与报道说明成为第一语言时归 Editorial。
- 对 Grid/Contact：Dynamic 允许偏离重复模数并强调尺度跳变；行列比较仍稳定时归 Grid/Contact。
- 对 Quiet：Dynamic 的留白具有方向和加速作用；静态停顿、中心凝视为主时归 Quiet。
- 对 Chromatic：Dynamic 的颜色只标记方向；色域分组或颜色节奏比图像方向更先被识别时归 Chromatic。

## 6. Chromatic Family Bible

研究依据：Research Dossier 的 A08、P06、M03、L03、G01/G03、DM01；重点采用 R-08（文字职责）、R-09（色彩组织信息）、R-10（跨线色域不改变书脊事实）与 R-12（真实照片色彩下验收）。

### 6.1 目标与情绪

Chromatic 让色彩成为可验证的信息结构：色域可以分组、建立节奏、标记入口或区分语义层，但照片、文字和 Photo Note 仍保持清楚关系。家族身份必须在关闭文字后仍能从色域与内容分区识别，也必须在去掉颜色后保留基本结构；换肤本身永远不是新布局。

### 6.2 内容适配

**适合：** 庆典、舞台、夜景、时尚、装置、食物、城市标识、主题色明显的系列；可按章节、情绪、地点或时间分组的照片；需要强入口和受控信息分区的内容。

**不适合：** 颜色已极度复杂且任何附加色都会争夺主体的照片；需要中性、档案式比较的系列；低对比文字不可避免的素材；只想更换背景而没有任何分组/节奏职责的页面；色觉依赖是唯一信息通道的内容。

### 6.3 网格、主轴、边距与书脊

- 基础骨架：6 列或 8 列网格；色域边界必须与列组、分带或内容组对齐，不能自由漂浮。
- 主轴：`horizontal`、`vertical`、`edge` 或 `around`；由色域边界和照片组共同确定。
- 页边距：短边的 5–10%；色域可延伸至页边，但文字和关键照片主体仍遵守安全边界。
- 书脊策略：page 为主。跨线色域只有在同一 spread 已由真实跨书脊照片或合法照片—Note `cross-page-pair` 证明后才允许；色域永远不能自证 spread。
- 层级：色域在 Photo 下，Photo 在 Text 下；文字必须完整落于唯一可确定的承载色域，不能横跨两个 surface。

### 6.4 图像尺度、数量与比例

- 主图典型面积：30–70%；次图典型面积 8–28%。
- 照片数：通常 1–5；6 张只用于明确色组或节奏序列。
- 优先比例：landscape、square、portrait 均可，取决于色域分组。ultra-wide 只用于横向色带或跨脊照片，默认高风险。
- 主次：单图可由色域建立入口；多图若面积接近，必须由色组、节奏或 label 明确关系，不能只靠颜色不同。
- 照片色彩与页面色彩：页面 token 必须衬托而非模拟照片主色；同色融合导致边界不清时视为失败。

### 6.5 三套强制色彩策略

1. **Zoned / 分区：** 2–3 个矩形色域分别承载标题、照片组或 Note。每个区有明确内容职责；不允许等同于随机拼色。
2. **Rhythmic / 节奏：** 2–3 个 accent 按固定序列重复，标记观看顺序或章节拍点。颜色次序必须能写成规则，不能每页自由选择。
3. **Single-accent / 强调：** `paper` 为主，一块 accent 只标记入口、选择或关键组。面积可以强但职责只能有一个。

扩展角色可以组合“分区 + 强调”或“分区 + 节奏”，但同一角色位最多三个功能色，且每种色都必须有唯一职责。

### 6.6 出血、留白与密度

- 目标密度：中密度为主，照片覆盖率约 35–70%；色域面积不计作照片密度。
- 出血：照片可局部/全出血，色域也可触边，但两者的边缘职责必须不同；不能让所有照片和所有色域同时四边触边。
- 留白：`paper` 本身是第四种结构资源，用来分隔色域和恢复可读性；没有 paper 呼吸带的多色页面必须特别证明层级仍清楚。
- 空色域：不得保留没有内容职责的装饰矩形。

### 6.7 阅读方向与进入点

- 入口由最大照片、唯一强调色或标题承载区三者之一承担；不得三者等权竞争。
- `zoned` 常用 `ltr/rtl` 或 `top-down`；`rhythmic` 可用 `around` 或线性重复；`single-accent` 使用 `edge` 或 center 入口。
- 颜色可以提示顺序，但不能成为唯一提示；结构、编号或内容分组必须提供第二条线索，照顾色觉差异和灰度环境。
- spread 中跨线色域只维持连续性，不改变 evidence 与 Photo Note 的数据绑定。

### 6.8 Note 能力

- 覆盖 `none | optional | required`，但 Note 必须完整落在一个确定色域或 paper 上。
- 允许 `adjacent`、`aligned`、`indexed`、`edge-related` 和合法照片—Note `cross-page-pair`；不采用 `overlay` 常规语法。
- caption 1–2 行、约 12–60 字符；note 2–4 行、约 40–120 字符；index 1 行、约 6–32 字符。
- Note 的前景 token 必须通过承载面静态对比；不能用颜色相似性暗示绑定。
- Optional Note 缺失时，Note Slot、照片和 Color Field 的几何均不改变；固定空白与色域必须仍以分组、入口、节奏或承载面职责独立成立。若某个色域只为 Note 服务，则 Note 必须 required；需要另一种色域结构的无 Note 状态必须拆成独立 Recipe，不能假设运行时删除或合并色域。

### 6.9 文字层级

推荐根据策略变化：

- zoned：`title > label > caption/note > folio`；
- rhythmic：`index/label > caption > folio`；
- single-accent：`title 或 label > caption/note > folio`。

`inverse-ink` 只用于完全落在高对比 accent 色域上的文字。index/label 不得仅靠颜色区别；还需要位置、顺序或文字内容。

### 6.10 对比与禁用组合

- 普通文字与承载面至少 4.5:1；小型 folio/index 除静态比值外，仍须通过单页视觉 Gate。
- 同一文字 Slot 不跨色域边界，不被更高层色域或照片部分覆盖。
- 禁止低对比组合：浅 accent + `muted-ink`、高明度 accent + `inverse-ink`、深 accent + `ink`，除非具体 token 值通过 Validator。
- 禁止结构组合：三种等权高饱和 accent + 高彩照片；红/绿或蓝/紫仅作为唯一分类线索；颜色与 Note 绑定一一对应却没有 index/关系数据；渐变、透明度、滤镜与混合模式。

### 6.11 scope 配比

建议 **10 个 page / 2 个 spread**。spread 分别承担“已有 `cross-gutter-photo` evidence 上的连续色域”和“required Photo–Note `cross-page-pair` 上的色域分组”；双图配对与色域本身都不计 evidence。

### 6.12 Do / Don't

**Do**

1. 为每个色域写出唯一信息职责。
2. 至少维护 zoned、rhythmic、single-accent 三种结构策略。
3. 让颜色以外的结构也能确认顺序和分组。
4. 让每个文字 Slot 完整落在单一承载面。
5. 在真实照片色彩下检查边界与对比。
6. 只声明在所有允许 Note 状态下都有固定职责的色域；只为 Note 服务时把 Note 设为 required。

**Don't**

1. 不把换背景色当作新 Recipe。
2. 不用跨线色域自证 spread。
3. 不让颜色替代 Photo Note 绑定或 index。
4. 不使用任意渐变、透明、滤镜、混合或 CSS。
5. 不让三个强调色和照片同时争夺第一入口。
6. 不只改变配色而保留相同 topology、主轴和阅读路径。

### 6.13 与其他家族的边界

- 对 Editorial：Chromatic 的色域承担信息组织；若颜色移除后只剩标题—主图—Note 的编辑层级，且色域只是辅助，归 Editorial。
- 对 Grid/Contact：Chromatic 可用重复模块，但颜色必须承担分组/节奏；若比较与 index 在无色时已完全主导，归 Grid/Contact。
- 对 Quiet：Chromatic 的颜色是显式结构而非纸面气氛；单图与留白主导、色彩可有可无时归 Quiet。
- 对 Dynamic：Chromatic 的路径由色域顺序/分组建立；尺度跳变、出血边和动作方向更先被识别时归 Dynamic。

### 7.3 跨家族冲突裁定顺序

当一个候选同时像两个家族时，按以下顺序裁定，而不是看名称或配色：

1. 先问其主要任务：叙事、比较、停顿、运动还是色彩组织？只能选一个。
2. 去掉颜色：若主要信息关系消失，优先 Chromatic；若完全不受影响，颜色只是辅助。
3. 去掉文字：若叙事入口消失，优先 Editorial；若比较/停顿/运动仍完整，分别归其他家族。
4. 统一所有照片面积：若结构目的消失，说明依赖主次或尺度跳变；前者偏 Editorial，后者偏 Dynamic。
5. 统一所有间距：若分组和扫描顺序消失，偏 Grid/Contact；若停顿消失，偏 Quiet。
6. 若仍无法唯一归类，候选不得进入 F3；先合并到更强家族或重写其第一识别层。
