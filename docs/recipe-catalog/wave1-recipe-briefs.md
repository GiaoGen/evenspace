## 0. 实施语义与统一计算

- `P(id;x,y,w,h;side;required;z;cover;bleed;gutter)` 是 Photo Slot。全部 `z=10`、`fit=cover`；未写的 bleed/gutter 均为 `false`。`C` 为 Color Field（`z=0`），`S` 为 static text（`z=20`），`N` 为 Note（`z=20`）。page canvas 为 `[0,1]×[0,1]`（3:4）；spread 为 `[0,2]×[0,1]`（派生 3:2，gutter `0.98–1.02`）。`left/right/cross` 是 `pageSide`。
- 所有 page safe area 为其非出血文字/照片的最小包络；spread safe area 的 x 可以到 `1.94`，但文字和非跨脊照片避开 `0.98–1.02`。Photo z=10、Color z=0、Text z=20，满足既有 band。所有 `paper/ink`、`paper/muted-ink`、`accent-1/inverse-ink`、`accent-3/ink` 均为已有 palette 中 ≥4.5:1 的已验证组合；没有 opacity、filter、gradient 或 blend mode。
- `AT(key; role; preset; chars/lines; owner=application)` 表示 authored static text：稳定 owner 为该 RecipeApplication，稳定 `contentKey=key`；`source=authored`。`LT` 表示 literal static text。未列 AT 的 Recipe 不支持 authored text。`N` 只绑定所列 Photo Slot；optional 缺失只留下既定空白，绝不 reflow、回收或删除色域。
- 物理 frame ratio = `(3 × width)/(4 × height)`。括号中的裁切损失为 source `1:1 / 4:5 / 3:2`，按 `1 − min(frame/source, source/frame)` 估算；它只是 cover 的保守构图预警，具体用 placement focus 处理。
- 每项的 empty：Editor 显示可点击空 Slot，Reader 不显示占位；partial：按 Slot 顺序填充、其余保持空；excess：超过 max 的尾部进入 `unplacedPhotoIds`，不删原图/Note；删除：Slot 保持空且后续不前移。Note `required` 缺失时兼容性拒绝 application；`optional` 缺失按前述固定构图。所有 page Recipe 只作用当前页；不宣称左右镜像。
